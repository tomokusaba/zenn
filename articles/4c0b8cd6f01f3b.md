## はじめに

M5Stack Tab5は、大きなタッチディスプレイを備えた開発ボードです。画面のあるIoTデバイスを作ってみたいと思っていても、「箱を開けたあと、最初に何をすればよいの？」と迷うことがあるかもしれません。

この記事では、Tab5を初めて手にしたところから、開封、初期確認、開発環境の準備を経て、ディスプレイに「Hello World!」を表示するまでを紹介します。私が実際に確認した内容や写真、測定結果は、確認後に追記するための箇所を残しています。

## M5Stack Tab5とは？

Tab5は、ESP32-P4を搭載したM5Stackの開発デバイスです。画面やカメラ、センサー、各種接続端子を備え、画面付きのIoT試作や組み込み開発に使えます。

| 項目 | 仕様 |
|------|------|
| 🧠 メインプロセッサ | ESP32-P4 |
| 📺 ディスプレイ | 5インチ、1280 × 720、タッチ対応 |
| 📡 無線 | ESP32-C6を使用したWi-Fi・Bluetooth |
| 🔌 接続端子 | USB Type-C、USB Type-A、microSDカードスロットなど |
| 📷 センサー類 | カメラ、6軸IMUなど |

仕様はハードウェアのリビジョンや販売構成によって異なる可能性があります。購入した個体の仕様や対応状況は、[M5Stack公式 Tab5 ドキュメント](https://docs.m5stack.com/en/core/Tab5)で確認してください。

## Step 4: Hello Worldを表示する 💻

次のスケッチでは、M5GFXを初期化し、画面に文字を表示します。

```cpp
#include <M5GFX.h>

M5GFX display;

void setup() {
  display.begin();
  display.setRotation(1);
  display.fillScreen(BLACK);
  display.setTextColor(WHITE);
  display.setTextSize(3);
  display.setCursor(40, 100);
  display.print("Hello World!");
}

void loop() {
}
```

スケッチをTab5に書き込み、画面に「Hello World!」と表示されることを確認します。コンパイルや書き込み時にエラーが出た場合は、公式クイックスタートのボード設定と、インストールしたM5GFXのバージョンを見直してください。
